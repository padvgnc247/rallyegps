# Rallye GPS

GPS copilote de rallye, sous forme d'application web installable sur iPhone (PWA).

- Tracé d'itinéraire point par point sur les routes et les chemins (BRouter), tracé à la main, import et export GPX.
- Détection automatique des virages et cotation rallye (1 = très serré, 6 = rapide), épingles, équerres, « se referme ».
- Notes dites à voix haute au bon moment selon la position GPS, modifiables une par une.
- Pente et relief à venir avec l'altimétrie IGN RGE ALTI : profil du prochain kilomètre, crêtes, cuvettes, fortes pentes.
- Mode reconnaissance : enregistre la trace GPS réelle et recalcule les virages à partir d'elle.
- Cartes Plan IGN, photo aérienne IGN et OpenStreetMap, téléchargeables le long du parcours pour un usage hors réseau.
- Mode jour et mode nuit, bascule automatique au lever et au coucher du soleil.

## Installation sur iPhone

Ouvrir l'adresse du site dans Safari, toucher Partager, puis « Sur l'écran d'accueil ».

## Avertissement

À utiliser en reconnaissance, sur épreuve fermée ou sur terrain autorisé. Sur route ouverte, le code de la route s'applique.
Les notes automatiques sont calculées à partir de données cartographiques : vérifiez-les toujours en reconnaissance.
